Your files remain on your computer. This page does not upload source data to a server.

Before running

  1. Use a current version of Chrome or Edge.
  2. Select the folder containing the preprocessed participant CSV files. Subfolders are included.
  3. Select a separate, empty output folder. The app will create cleaned CSVs and logs/ within it.

Advanced options

These settings use the current script defaults. Change them only when your cleaning plan requires it.

Overwrite protection: source files are never edited. The run stops before writing if the output folder is not empty. If a processing error occurs after writing begins, the app removes files it created where possible.
